The independent check is the self-test run in a fresh process plus step 5's real run; the PR body says "not Two-Key graded". (c) A mutation whose `old` text matches zero times or twice is refused with exit 1, never applied.
7. What could go wrong, already ruled. The script leaves a mutated file behind: restore runs in a `finally` block and a hash check follows, and the self-test crashes a run on purpose to prove it. Output mangles on Windows: `PYTHONUTF8` and `errors="replace"` (session 103's drafter lost calls to this). A stuck pytest: the 600 s default timeout kills it and exits 1.

9. Not in this session. `receipts.py`. The Haiku receipts agent ruling. The G1.1 edges and the PR #116 and #119 readings in the backlog's Open questions. Each stays on the backlog.
10. Words. Scratch folder: the temporary directory a drafter works in, never the repo. Prototype: a scratch copy of the `taskcontract` package edited until the draft passes. Mutation: a one-line break of the prototype that a pinned test should catch. Red: every test fails on the missing behavior. Green: every test passes on the prototype.
