10. Words. Workflow file: `.sdlc/workflow.md`, whose `mermaid` flowchart holds the nodes and edges and whose settings table holds a row per node. Node: a stage's place in the flowchart, named by its id (`feature`, `design`, `execution`, `review`). Edge: an arrow from one node to the next; its label names the file handed over. Settings row: a node's row in the table: agent model, effort, operator or seat. Reader: `taskcontract/workflow.py`, which reads the file and refuses a fault. Prototype: the drafter's scratch copy of the files the unit changes, used only to prove the tests can pass. Two-Key: the grade of a unit by an agent that re-runs its receipts independently.
