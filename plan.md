10. Words. Team member: one of the five operators of the execution row; QA, the QA verifier, the Developer and the Dev verifier each run as one workflow agent, and the Orchestrator is the session. Workflow: a script the Workflow tool runs, which starts agents with a set model and effort. Plugin root: the folder Claude Code installs the kit's plugin into, `${CLAUDE_PLUGIN_ROOT}`; the plugin ships the tracked tree. Execution row: the line of `.sdlc/workflow.md` naming the execution node's model (`sonnet`) and effort (`high`). Consumer: a repository that installs the kit. Task file: `.git/sdlc-task.json`, naming the running task, its operator and its round, which the wall reads. Prototype: a scratch copy of the code that the old drafter changed to prove its tests can pass; the shipped QA writes none. Probe: a throwaway run that measures one fact before the build leans on it. Drafter, developer, Two-Key: the build's three agents (tests first, then code, then an independent grade). Prove-red: the record that the new tests fail before the code exists.
