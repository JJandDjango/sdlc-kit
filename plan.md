10. Words. Node: a stage's place in the flowchart of `.sdlc/workflow.md`, named by its id (`feature`, `design`, `execution`, `review`). Settings row: a node's row in the file's table: agent model, effort, operator or seat. `node`: the new command, `python -m taskcontract node <id> [--print]`. Workflow scripts: the four `.claude/workflows/*.js` files that run this repo's agents through the Workflow tool. Stand-in: a fake `claude` the tests put on PATH, which records its arguments and exits. Manual receipt: a live run whose text is saved as evidence, since no test can run it. Prototype: the drafter's scratch copy of the files the unit changes, used only to prove the tests can pass. Two-Key: the grade of a unit by an agent that re-runs its receipts independently.
